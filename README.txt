JARVIS Touch - build steps
1. Is folder ko GitHub repo me push karo (branch: main)
2. Repo > Actions > "Build APK" run hone do (~4-5 min)
3. Run ke Artifacts se JarvisTouch-apk download karo, zip se app-debug.apk nikalo, install karo
4. App kholo > Accessibility ON karo (JARVIS Touch) > API key save > command do
